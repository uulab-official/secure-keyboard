# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately to the repository maintainers with the affected version, platform, reproducible steps, and a minimal proof of concept that contains no real credential or personal data.

Use the repository's [private GitHub Security Advisory form](https://github.com/uulab-official/secure-keyboard/security/advisories/new). If that form is unavailable, contact the repository administrators through a private channel before disclosure; do not move the report to a public issue.

## Scope

Reports involving secret exposure, unsafe public APIs, protocol downgrade, replay acceptance, logging, clipboard/autofill leakage, or platform capture handling are in scope.

## Supported releases

Until the first stable release, only the latest development branch is supported. Release support and coordinated disclosure timelines will be published with the first stable version.
